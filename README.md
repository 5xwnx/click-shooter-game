# Click Shooter: Neon Hunt

마우스로 적을 클릭해 맞추는 데스크톱 웹게임입니다.

## 추가된 기능

- 🔊 클릭 효과음과 게임 종료 효과음 (시작 화면에서 켜고 끌 수 있음)
- 🎵 별도 파일 없이 Web Audio API로 만든 효과음
- ⭐ 시간이 지날수록 적이 더 많이 나타나는 난이도/레벨 시스템
- 🎯 연속 적중 콤보: 콤보가 높을수록 한 번에 얻는 점수 증가
- 🏆 최고 점수 자동 저장 (`localStorage`)
- 💥 클릭 폭발 파티클과 점수 팝업 이펙트

## 실행

`index.html`을 브라우저에서 열고 **게임 시작**을 누르세요. 별도 설치가 필요하지 않습니다.

> 이 버전은 노트북/데스크톱 마우스 플레이에 맞춰져 있습니다.
